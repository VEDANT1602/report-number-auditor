# Data and evaluation boundary

All inputs are original fixtures generated by `generate.py` from fixed seeds. No customer, employee, medical, biometric or employer records are included. The fixture design defines the task and is a material limitation. Source projects provide conceptual topics, not copied data or benchmark targets.

The authored contracts measure protocol conformance. The system does not read unrestricted prose, infer scientific causality, authenticate an experiment owner, or establish whether the source measurement itself is correct. A trusted artifact plus a structured claim is required.

The manifest binds committed core code, input bytes, model artifacts where applicable and result files. It is an integrity commitment, not proof that the simulator reflects a production population. Changing core code requires rerunning the experiment before refreshing the manifest.

`digits` specifies the numerical acceptance tolerance, not a formatting rule for displayed decimal places. The auditor checks a supplied numeric value within that tolerance; it does not inspect rendered report typography.
